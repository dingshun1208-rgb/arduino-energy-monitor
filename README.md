# Arduino Energy Monitor for DIY USB Bluetooth Speaker

## Project Goal
Build a smart energy monitoring system for my DIY USB Bluetooth speaker. Measure power consumption with INA219, log data to SD card, control standby power with a relay, and upload data to ThingSpeak via ESP32.

## 12-Month Roadmap
- [ ] Phase 1: Arduino Basics (LED, Button, Serial, PWM, LM35, LCD, Motor)
- [ ] Phase 2: INA219 Power Measurement + LCD Display
- [ ] Phase 3: SD Card Logging + Relay Control
- [ ] Phase 4: ESP32 + ThingSpeak Cloud Integration

## Current Equipment
- ELEGOO UNO R3 Basic Starter Kit
- Freenove I2C LCD 1602
- Robojax LM35DZ Temperature Sensor
- Digital Multimeter (arriving soon)
